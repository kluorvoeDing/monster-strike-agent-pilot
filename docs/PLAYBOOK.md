## 1. iPhone 控制環境與通訊架構

### 1.1 呼叫規範與權限管理
- **服務本體**：`iphone-use serve`（本機 127.0.0.1:44321，監控 CoreDevice / USB 轉發）。
- **工具入口**：`iphone-use-mcp` 支援標準 MCP JSON-RPC 通訊協議。
- **租約鎖定（重要）**：
  - 每個進程在控制前會取得 `owner` 租約（預設名為 `mcp-<PID>`）。
  - **最佳實踐**：在調用腳本時固定環境變數 `export IPHONE_USE_OWNER="agent-session"`，以防多進程間互相報 `409 phone_owned`。
  - **操作結束時務必呼叫 `phone_release_owner`** 釋放控制鎖，讓手機進入 `owner: null` 的待命狀態。

### 1.2 常用 MCP 工具清單
1. `phone_status`：確認 `drivable == true`。若為 false 且處於 `idle_release`，呼叫 `phone_reconnect` 重連。
2. `phone_elements`：
   - 怪物彈珠為 Metal/遊戲引擎繪製，無原生 iOS Accessibility 樹狀結構。
   - **必須帶入參數 `{"ocr": "force"}`**，呼叫 Apple Vision 引擎從畫面畫素中提取文字與相對座標（0.0 ~ 1.0）。
3. `phone_screenshot`：截取高畫質畫面進行圖像色彩與戰局分析。
4. `phone_run_steps`：批次下發動作指令（`tap`、`drag`、`swipe`、`pause`），能大幅降低網絡與對話延遲。

## 4. 戰鬥操作物理與友情技彈射算法

### 4.1 拉射機制（Slingshot Physics）
- **反向拉射**：欲將彈珠朝向量 $\vec{V}$ 發射，手指拖曳方向必須為反方向 $-\vec{V}$。
- **拖曳距離閥值**：拖曳距離至少需超過畫面高 10%（約 120 像素），否則系統判定為取消瞄準。
- **手勢指令結構**：
  ```json
  {
    "kind": "drag",
    "x1": 0.50, "y1": 0.55,
    "x2": 0.35, "y2": 0.70,
    "hold_ms": 200,
    "duration_ms": 300
  }
  ```
  *(由此產生的發射向量為朝向右上 $(0.65, 0.40)$ 飛出)*。

### 4.2 弱關/刷關核心策略：「友情引爆為王」（如路西法艦隊）
- **路西法（獸神化·改）特性**：
  - 核心價值在於其超強能量環6（High Energy Circle）。只要觸碰隊友路西法，周圍全螢幕瞬間爆發毁滅性傷害。
  - 本身為反射型，但只要在第一或第二個反彈節點碰到其他路西法，就能觸發連鎖轟炸。
- **精準彈射計算公式**：
  1. 透過 `phone_elements` (OCR) 取得當前回合球標記（如 `4th`）及各隊友（`1st`、`2nd`、`3rd`）的座標 $(x_i, y_i)$。
  2. 尋找隊友最密集的質心 $(\bar{x}, \bar{y})$，或優先鎖定路西法座標。
  3. 算出由發射球 $(x_0, y_0)$ 指向質心的發射方向 $\vec{d} = (\bar{x} - x_0, \bar{y} - y_0)$。
  4. 反向換算拖曳落點：
     $$\text{drag\_to} = (x_0 - 0.25 \cdot \frac{d_x}{\|\vec{d}\|},\, y_0 - 0.25 \cdot \frac{d_y}{\|\vec{d}\|})$$
  5. 執行 drag，彈珠必將直接穿透或反彈直撞隊友！

### 4.3 實戰操作檢討與隊友直瞄狙擊演算法（Direct Ally Targeting）
> **重大教訓與檢討**：
> 先前採用「全體隊友平均質心」且將拉射錨點設在螢幕中心 $(0.50, 0.55)$，導致嚴重邏輯錯誤：
> 1. 當 4 顆球左右均勻分佈時，質心橫座標恰為 $x=0.50$，導致計算出的發射向量變成垂直無角度，手指拉出「直上直下」的無效盲射。
> 2. 質心往往落在空無一物的地板中央，彈珠朝質心發射等於「瞄準空氣」，完全背離了「直接撞擊路西法」的初衷。

#### 修正後的正統瞄準演算法：
1. **鎖定發射球**：取得當前回合球（Active Ball）的真實座標 $(x_0, y_0)$。
2. **指定目標隊友**：直接鎖定場上最近或最容易命中的另一隻隊友（路西法）之精確座標 $(x_t, y_t)$，**絕對不要算平均值**！
3. **直線狙擊向量計算**：
   - 發射向量：$\vec{V} = (x_t - x_0,\, y_t - y_0)$
   - 正規化單位向量：$\hat{u} = \frac{\vec{V}}{\|\vec{V}\|}$
   - 反向拉射終點：從觸控起點 $(x_0, y_0)$ 沿著 $-\hat{u}$ 反向拖曳至少 0.20 距離（約 240 像素）：
     $$\text{drag\_to} = (x_0 - 0.20 \cdot u_x,\, y_0 - 0.20 \cdot u_y)$$
4. **實戰效果**：彈珠出射第一時間必定精確貫通/撞擊該路西法，零時差引爆超強能量環，杜絕任何直上直下或亂甩的情形。

### 4.4 進場與結算時間差檢討（Latency Tuning）
1. **進場鏈接點擊間隔**：
   - 關卡 $\to$ 單人：1.5 秒
   - 單人 $\to$ 幫手選擇：1.5 秒
   - 幫手選擇 $\to$ 隊伍確認：2.0 秒（載入好友名單需時較長，勿過快發送出擊點擊，否則出擊按鈕尚未就緒）
   - 隊伍確認 $\to$ 出擊：1.5 秒
2. **結算動畫時差**：
   - `STAGE CLEAR` 出現後，Boss 死亡爆炸演出約需 **2.5 秒**。
   - 必須於 2.5 秒後才點擊攻略提示 `OK` $(0.501, 0.605)$，隨後接 4 次間隔 350ms 的連續點擊 $(0.500, 0.650)$ 開蛋，最後連點兩次右下角 `OK` $(0.497, 0.921)$，即可在 5 秒內精準歸回大廳。

## 5. 高難度關卡（轟絕 / 爆絕 / 黎絕 / 天魔 / 禁忌）作戰框架

在高難度關卡中，官方通常會設置**「友情技無效（0.01倍）」**、**「直毆倍率大幅提升」**或**「即死倒數計時」**。路西法或純友情轟炸隊伍將完全無法通關。

未來面對高難度關卡時，Agent 必須執行以下**三階段作戰流程**：

```
[階段一：子代理網路情報調研]
  └── 派 research 子代理檢索 GameWith / 巴哈姆特 關卡攻略資料
  └── 萃取：必要被動、擊種限制、核心機制、推薦角色榜
         │
[階段二：背包檢索與編隊配置]
  └── 比對玩家背包是否具備 S 級適性角色
  └── 檢查守護獸與果實配置
  └── 自動進入「怪物」選單完成隊伍編組
         │
[階段三：機制解謎式走位實戰]
  └── 遵循打倒順序（軟硬怪、復活連動、踩板升攻）
  └── 弱點反覆往返直毆 / 卡點攻擊
  └── 危機時果斷開啟 SS 或召喚守護獸
```

### 5.1 階段一：研究子代理（Research Subagent）執行指引
當使用者指定挑戰轟絕/高難關卡時，呼叫 `research` 子代理執行精確檢索：
- **搜尋關鍵字**：`怪物彈珠 <關卡名稱> 攻略 GameWith 巴哈姆特`
- **必須整理產出的情報規格**：
  1. **必要被動（Gimmick）**：
     - 反傷害壁 (ADW)、反重力 (AGB)、反傳送 (AW)、掃雷/飛行 (MS/Flight)、反減速壁 (ABlocks / Anti-Slow)、反魔法陣 (Anti-Warp/Magic)。
     - 是否有秒殺型地雷或觸碰即死傷害壁？（此類陷阱不對應即死）。
  2. **擊種限制**：
     - 貫通制限怪（軟軟，必須用反射擊殺）。
     - 反射制限怪（硬硬，必須用貫通擊殺）。
  3. **關卡特異機制**：
     - 弱點效果提升、屬性效果超絕提升、踩踏板升攻（向量踏板 / 攻速踏板）、集火弱點露出一擊必殺。
  4. **擊倒順序（Target Order）**：
     - 例如：相互復活小怪需同回合擊殺 $\to$ 攻擊力提升怪物 $\to$ 中 Boss 弱點。

### 5.2 階段二：角色背包檢查與編隊
- 進入「怪物」$\to$「隊伍編組」或關卡準備頁面的「紀錄/大家的過關隊伍」。
- 優先使用官方提供的「大家過關隊伍」快速套用玩家已擁有的高階適性角色。

### 5.3 階段三：實戰機制走位
- **直毆型走位**：不再隨意亂甩，計算反射路徑與壁面夾角（如：入角等於出角的反射原理），讓彈珠精準卡入 Boss 與牆壁之間（卡肉輸出）或反覆直擊弱點。
- **危急管理**：若血量低於 30% 或即死倒數剩餘 1 回合，優先使用延遲型 SS、回復型守護獸或爆發型大招。

## 8. 訓練冒險後段防坑與地雷關卡速查（Subagent 深度背調）

### 8.1 為什麼「純 4 隻路西法艦隊」在後段關卡會陷入死循環？
1. **黑洞陷阱 (Warp / ワープ)**：路西法**無反傳送 (AW)**。一旦場上出現黑洞，彈珠被黑洞吸入後會以隨機方向噴射並減速停滯，無法直瞄撞擊隊友引爆能量環，導致友情技零觸發，面對復活怪會陷入「無限復活死循環」。
2. **魔法陣 (Magic Circle)**：踩單數個變成**小雞（ひよこ）**，攻擊力與超絕能量環威力暴跌至 **33%** 且無法開啟 Strike Shot。
3. **連攜技能封印**：純 4 隻路西法（同為妖精族）若未滿運，連攜技能條件（需 2 體以上不同種族）會直接關閉，失去「超反重力」與「弱點殺手EL (3倍)」。
4. **高防蠍子 (サソリ)**：路西法為單段爆發傷害，對蠍子每次固定僅扣 1 點血，缺乏高 Hit 數導引彈或毒友情難以破防。
